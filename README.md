# Folio

백엔드 개발자가 매일 실무 시나리오형·CS 개념형 서술형 문제와 단답형 문제를 풀고, LLM 감독관에게 채점과 학습 피드백을 받는 데스크톱 앱입니다(macOS, Windows).

- 매일 시나리오형 1문제와 개념형 1문제(설정에 따라 3문제), 점수가 낮았던 주제의 약점 복습 문제, 단답형 3문제를 출제합니다.
- 제출하면 점수, 관점별 점수, 잘한 점, 부족한 점, 모범 답안, 추가 학습 주제를 보여 줍니다.
- 원하는 형식·유형·주제·난이도로 추가 문제를 풀 수 있고, 한 번 출제된 문제는 다시 나오지 않습니다.
- 문제와 출제 방식에 남긴 피드백은 이후 문제 생성에 반영됩니다.
- 풀다가 막히면 힌트를 3번까지 받을 수 있습니다(1회당 5점 감점). 힌트를 다 쓰고도 막히면 나중에 다시 풀기로 미루고, 3일 뒤 오늘의 문제로 다시 받습니다.
- 채점 뒤에는 감독관이 약한 부분을 파고드는 꼬리 질문을 내고, 채점이나 모범 답안에 대해 직접 질문할 수도 있습니다.
- 채점과 모의 면접에서 추천된 공부거리는 학습 노트에 키워드별로 모입니다. 키워드를 누르면 LLM이 추천 이유에 맞춰 정리한 설명(핵심 요약, 동작 원리, 실무 적용, 흔한 오해, 스스로 점검 질문)을 읽으며 공부하고, 메모와 완료 표시를 남길 수 있습니다.
- 문제 은행의 문제마다 출제자가 꼽은 학습 주제(`relatedStudyTopics`)도 학습 노트에 키워드별로 모이고, 노트마다 그 개념이 필요한 문제가 함께 표시됩니다. 문제 상세 화면에서 그 문제에 필요한 학습 노트로 바로 갈 수 있습니다.
- 모의 면접은 두 가지입니다. 제한 시간 세션은 여러 문제를 시간 안에 연달아 풀고 끝난 뒤 결과를 봅니다. 대화형 면접은 면접관의 질문에 짧게 답하면 답에 따라 꼬리 질문이 이어지고, 끝나면 평가 보고서를 받습니다.
- 출제 주제를 켜고 끌 수 있고, Redis·Elasticsearch처럼 원하는 주제를 직접 추가할 수 있습니다.
- 정한 시각에 오늘의 문제 알림을 받고, 연속 학습 일수와 학습 기록을 볼 수 있습니다.
- 출제·채점·면접·학습 노트 규칙은 `skills/` 의 skill 파일 네 개가 원본이며, 앱과 Claude Code·Codex 터미널이 같은 규칙을 씁니다.

## 폴더 구조

| 경로 | 내용 |
|---|---|
| `skills/` | 출제(`daily-study-question-author`)·채점과 힌트·꼬리 질문(`daily-study-grader`)·대화형 면접(`daily-study-interviewer`)·학습 노트(`daily-study-tutor`) skill |
| `schemas/` | LLM 출력 JSON Schema, 분류 체계(`taxonomy.json`) |
| `seed/questions/` | 초기 문제 은행 77문제 |
| `src/main/` | Electron 메인 프로세스: 저장, 출제, 채점, LLM 실행 |
| `src/renderer/` | 화면(React) |
| `scripts/` | 설치(`setup.mjs`), 문제 은행 검증(`validate-seed.mjs`), 앱 아이콘 렌더링(`render-icons.mjs`) |
| `build/` | 앱 아이콘 원본(SVG)과 설치 파일에 들어가는 PNG |

## 개발 명령

| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발 모드 실행 |
| `npm test` | 단위 테스트 |
| `npm run typecheck` | 타입 검사 |
| `npm run validate:seed` | 초기 문제 은행 형식·중복 검사 |
| `npm run dist:mac` / `npm run dist:win` | 설치 파일 빌드 |
| `npx electron scripts/render-icons.mjs` | `build/` 의 아이콘 SVG를 수정한 뒤 PNG 다시 만들기 |
